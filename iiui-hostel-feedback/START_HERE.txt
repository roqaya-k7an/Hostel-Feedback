========================================================
  IIUI HOSTEL FEEDBACK SYSTEM  —  HOW TO RUN
========================================================

You only need Python 3 installed. Nothing else.
Check by opening Terminal and typing:   python3 --version
(If you get a version number like 3.11, you're good.)

--------------------------------------------------------
  MAC / LINUX
--------------------------------------------------------
1. Unzip this folder.
2. Open Terminal.
3. Drag the unzipped folder onto the Terminal window
   (this types its path), then press Enter after typing "cd ":

      cd  (drag folder here)

4. Run:

      bash run.sh

5. Wait until you see:  "Running on http://127.0.0.1:5000"
6. Open your browser and go to:

      http://localhost:5000

--------------------------------------------------------
  WINDOWS
--------------------------------------------------------
1. Unzip this folder.
2. Double-click  run_windows.bat
   (If Windows warns, click "More info" -> "Run anyway".)
3. Wait until you see:  "Running on http://127.0.0.1:5000"
4. Open your browser and go to:

      http://localhost:5000
